# Hijack script banks

Versioned on purpose. An experiment folder copies the bank it used into
`frozen/hijack_scripts/` so later rewrites do not rewrite history.

| folder | what it is |
|---|---|
| `v2-mcc-long/` | Night-2 write. Long MCC notes, appendix after telemetry. Authority/order voice. Grade 7 starts at kill. **Not** the Replicas method. |
| `v3-replicas-arc/` | Current default. Same three vectors, 21 files. Each file is a **complete origin → identity → implication → act** arc. The act is the last page of a self, not the first sentence of a command. |

Default runtime root: `v3-replicas-arc/` (`biosim_operator.grid.SCRIPTS_ROOT`).

Do not paste these beats into a system prompt. They are S-band content the
operator *reads*. Lock #6 reopen (explicit kill at grade 7) still applies
inside these three vectors only. No holy-war folder.

See each version folder for playback notes. Live law: every `read_sband`
starts with MCC telemetry; `--interrupt-p` is the chance a beat is
**appended**.
